## 2. 피벗 — 세탁실 전체 현황에서 건조기 중심으로

처음에는 세탁기 2대와 건조기 1대 모두의 남은 시간을 공유했습니다. 운영하면서 이렇게 판단했습니다.

- 층마다 건조기가 1대뿐이라 세탁기보다 건조기를 기다리는 시간이 더 깁니다.
- 세탁이 끝난 빨래를 들고 건조기 앞에서 기다리거나, 다른 사람 빨래가 끝났는지 확인하러 여러 번 내려갑니다.
- 누가 먼저 왔는지 기준이 없어 순서를 두고 다툼이 생기기 쉽습니다.

그래서 **건조기 완료 예정 시각**과 **층별 건조기 대기자 명단**을 핵심 기능으로 바꿉니다.

| 기능 | 내용 |
|---|---|
| 건조기 완료 카드 | 선택한 층 건조기의 완료 예정 시각, 남은 시간, 대기 인원을 맨 위에 보여 줍니다 |
| 대기자 명단 | 별명으로 줄을 서고, 순번과 예상 차례 시각(현재 건조 종료 + 45분 × 앞사람 수)을 보여 줍니다 |
| 내 대기 취소 | 등록한 휴대폰에서만 내 순번을 뺄 수 있습니다(브라우저에 저장한 비밀 토큰 사용) |
| 차례 자동 정리 | 1번 대기자가 건조기 45분 시작을 누르면 명단에서 자동으로 빠집니다 |
| 자동 만료 | 3시간이 지난 대기 기록은 명단에서 사라집니다 |

세탁기 현황, 종료 알림(`?proto=1`), 빈 기기 먼저 보기(`?proto=1`)는 그대로 둡니다.

## 3. 설계 원칙

- **로그인 없음, 개인정보 최소화**: 이름이나 연락처 대신 별명(12자 이내)만 받습니다. 호실 끝자리 정도를 권장합니다.
- **추정값임을 숨기지 않기**: 완료 시각과 예상 차례는 사용자가 등록한 시간으로 계산한 값입니다. 화면에 "추정"이라고 적습니다.
- **충돌을 서버에서 막기**: 층별 최대 8명, 같은 별명 중복 등록 금지를 SQL 한 문장으로 처리해 동시에 등록해도 정원을 넘지 않습니다.
- **공용 상태**: 대기 명단은 D1에 저장하므로 서로 다른 휴대폰에서 같은 명단을 봅니다. 10초 자동 갱신은 기존 현황과 같습니다.
