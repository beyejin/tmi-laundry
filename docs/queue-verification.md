## 자동 검증

- 타입 검사와 배포 빌드 통과
- 단위 테스트 72개 통과
- 기존 현황판 API 테스트 13개 통과
- 최신 빌드의 격리 대기 API 테스트 13개 통과
- Drizzle 모델과 SQL 마이그레이션의 8개 테이블 및 인덱스 대조
- 공개 API의 사용자 정보 미포함 확인
- 원격 D1 추가 마이그레이션 적용과 기존 기록 보존 확인

합계 98개 테스트가 통과했습니다. Push 암호문은 테스트 수신 키로 실제 복호화하여 본문을 대조했습니다. 외부 알림 도착을 자동 테스트 결과로 간주하지 않습니다.

## 브라우저 검증

격리 DB의 가상 계정으로 Chrome에서 확인했습니다.

1. 알림 링크로 진입했을 때 QR 시작 버튼이 열리지 않음
2. 해당 QR에서 빈 상태 확인 후 36분 사용 등록
3. 본인 사용 기록의 시간 수정과 저장 반영
4. 다음 이용자의 미수거 확인 후 동일 순번 유지와 기기 재호출 차단
5. 현재 이용자의 수거 완료 후 재배정과 해결 이력 보존
6. 390px 화면에서 가로 넘침 없음
7. 운영 배포 화면에서 기존 현황 유지와 대기제 준비 상태 표시

모바일 크기 검증은 브라우저 에뮬레이션입니다. 실제 아이폰과 안드로이드의 화면 종료 및 잠금 상태 Push는 아직 검증하지 않았습니다.
